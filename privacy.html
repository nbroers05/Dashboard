Privacy policy

Dashboard of N. Broers · nbroers05.github.io/Dashboard · updated 13 November 2026

This dashboard is a personal project for own use. It is not a service for others.

Which data

After permission via Google, the dashboard reads, read-only:

  • Google Calendar: events, to show them on the dashboard.
  • Gmail: sender, subject and a short preview of unread mail.
  • Google Health: steps, sleep and heart rate.

Where it stays

The data is only processed in the user's own browser and on the user's own computer. There is no server: nothing is stored with or shared with third parties, and nothing is used for advertising or analytics. Access keys are only kept in the browser (localStorage) or in a file on the user's own computer.

Revoking access

You can revoke the access at any time via myaccount.google.com/permissions.

Google API data

The use of data from Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions: via the email address listed with the app in Google.
